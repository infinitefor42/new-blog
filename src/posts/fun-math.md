# 拉马努金生日幻方：用你的生日打造专属数学魔法

## 1. 什么是拉马努金生日幻方？
印度天才数学家**拉马努金 (Srinivasa Ramanujan)** 曾随手写下一个 $4 \times 4$ 的神奇方阵。它的奇妙之处在于：无论横向、纵向、对角线，甚至是四个角、中间四个数的相加和，全部等于 **139**！

更令人惊叹的是，这个幻方的第一行数字 `22-12-18-87`，正是拉马努金的出生日期：**1887年12月22日**。

## 2. 幻方的“神奇特性”
以拉马努金的幻方为例，其“幻方常数”（即每一组数字的和）均为 **139**：
* **横向**：每一行的 4 个数字相加 = 139
* **纵向**：每一列的 4 个数字相加 = 139
* **对角线**：主、副两条对角线数字相加 = 139
* **四个角**：方阵最外侧四个顶角的数字相加 = 139
* **中心区**：最中间的 4 个数字相加 = 139

## 3. 动手实践：制作你的专属生日幻方
你不需要是天才，只要套用下面的**万能模板**，就能将任何一个日期转化为幻方。

### 第一步：拆分日期
将你的生日（或任何纪念日）拆分为四个数字：$A, B, C, D$。
* $A$ = 日
* $B$ = 月
* $C$ = 年份前两位
* $D$ = 年份后两位

> **例子：2024年09月04日**
> * $A=04, B=09, C=20, D=24$
> * **幻方密码（和）**：$4 + 9 + 20 + 24 = 57$

### 第二步：套用万能模板
将 $A, B, C, D$ 代入下表进行计算：

| | | | | |
| :--- | :---: | :---: | :---: | :---: |
| **第一行** | $A$ | $B$ | $C$ | $D$ |
| **第二行** | $D+1$ | $C-1$ | $B-3$ | $A+3$ |
| **第三行** | $B-2$ | $A+2$ | $D+2$ | $C-2$ |
| **第四行** | $C+1$ | $D-1$ | $A+1$ | $B-1$ |

### 第三步：计算结果
照着填完这 16 个格子，奇迹就会发生！所有的横、竖、斜及特殊组合的和，都会等于你的“幻方密码”。

## 4. 特别说明
* **关于负数**：在计算过程中，某些位置可能会出现负数。这完全没有关系，它不会影响幻方的成立和数学上的严谨性。
* **理科生的浪漫**：学会这一招，下次朋友过生日时，现场给心仪的对象画一个专属生日幻方，绝对是最硬核且高级的理科式浪漫！
