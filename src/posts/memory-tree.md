## 项目简介

记忆树是一个基于 Three.js 的 3D 照片展示组件，灵感来源于圣诞树上悬挂的装饰球——把照片以螺旋形态排列在三维空间中，配合粒子背景和自动旋转，营造沉浸式的回忆浏览体验。

## 技术栈

- **Three.js** — 3D 渲染引擎
- **React Three Fiber** — Three.js 的 React 封装
- **@react-three/drei** — 常用 3D 组件（OrbitControls、Float 等）

## 功能特性

- 1000 个粒子构成的螺旋树骨架，青紫双色交替
- 照片节点始终面向相机（billboard 效果）
- 自动旋转 + 鼠标拖拽探索
- 悬停时青色发光边框
- 支持图片和视频两种媒体类型

## 交互说明

- **拖拽旋转**：鼠标左键拖动视角
- **点击照片**：弹出大图预览（支持视频自动播放）
- **自动旋转**：松手后缓慢回正
