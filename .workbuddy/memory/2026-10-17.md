## 访问统计不计数根因：page_views 未暴露 Data API
- 现象：表 0 行、控制台无报错、Network 无 page_views 请求。根因线索：Table Editor 中 guestbook_messages 有地球图标（可通过 Data API 访问），page_views 没有 → PostgREST 路由不到表（404 / PGRST205）。
- 修复：表级开启 Expose table via Data API + 确认 public 在 Exposed schemas + notify pgrst reload schema + grant insert on page_views to anon（已补进 supabase/page_views.sql）。
