    规则解读

    • 食物分值：普通食物（红色）+10分，金色加分食物 +30分，闪电加速食物 +10分并加速 20 步（1.5 倍速）
    • 游戏模式（单选）：经典 / 限时挑战 / 无尽 / 关卡，四选一
    • 经典模式：撞墙或撞到自己身体即结束
    • 限时挑战：30 / 60 / 120 秒可选，时间到即结束；3 秒内连续进食触发连击加分
    • 无尽模式：自动开启穿墙，永不撞墙，可无限游玩
    • 关卡模式：避开障碍物地图，达到目标分数即可过关，共 8 关逐关解锁
    • 修饰开关（可多选）：穿墙模式（从对侧穿入）、难度递增（随分数加快速度），可与任意模式组合
    • 倍速：可调整整体游戏速度（0.5x ~ 3x）
    • 排行榜：按模式独立排行，穿墙/无尽的高分不会碾压经典榜单
    • 皮肤解锁：海洋（单局 300 分）、黄金（单局 500 分）、赛博（通关全部关卡）
