# 贪吃蛇游戏技术优化计划

## 目标
实现三项技术优化：
1. Canvas 渲染 - 替代 DOM 网格
2. 帧率优化 - 使用 requestAnimationFrame
3. 资源预加载 - 音效预加载

## 文件
- `public/games/Snake_Game/index.html` - 唯一需要修改的文件

## 实现方案

### 1. Canvas 渲染改造

**替换 DOM 网格为 Canvas：**
```html
<!-- 替换 <div id="game-board"> 为 -->
<canvas id="game-board" width="400" height="400"></canvas>
```

**新增渲染函数：**
- `initCanvas()` - 初始化 Canvas 和 2D Context
- `drawCell(x, y, color, type)` - 绘制单个格子
- `drawSnake()` - 绘制蛇身（渐变色）
- `drawFood()` - 绘制食物（带动画）
- `drawGrid()` - 绘制网格背景
- `render()` - 主渲染函数

**蛇身渐变效果：**
- 头部：深绿 #2E7D32
- 身体：从 #388E3C 渐变到 #81C784
- 使用 HSL 颜色空间平滑过渡

**食物动画：**
- 使用 sin 函数实现呼吸效果
- 红色圆圈 + 光晕

**吃食物特效：**
- 粒子爆炸效果（8-12 个小粒子向外扩散）
- 使用数组存储活跃粒子

### 2. 帧率优化

**分离渲染和逻辑循环：**
```javascript
// 游戏逻辑循环（控制速度）
function gameLoop() {
    if (!isRunning) return;
    Module.ccall('game_loop', null, [], []);
    updateGameState();
    const interval = 150 / gameSpeed;
    gameLoopId = setTimeout(gameLoop, interval);
}

// 渲染循环（60fps）
function renderLoop() {
    render(); // 绘制 Canvas
    updateParticles(); // 更新粒子
    requestAnimationFrame(renderLoop);
}
```

**关键改动：**
- `gameLoop()` 保持 setTimeout，控制游戏速度
- 新增 `renderLoop()` 使用 requestAnimationFrame，60fps 渲染
- 游戏状态更新在 gameLoop，视觉渲染在 renderLoop

### 3. 资源预加载

**添加音效：**
- 吃食物音效
- 游戏结束音效

**预加载机制：**
```javascript
const sounds = {
    eat: new Audio('data:audio/wav;base64,...'),
    gameOver: new Audio('data:audio/wav;base64,...')
};

// 预加载
Object.values(sounds).forEach(sound => {
    sound.preload = 'auto';
    sound.load();
});
```

**触发时机：**
- 吃到食物时播放 sounds.eat
- 游戏结束时播放 sounds.gameOver
