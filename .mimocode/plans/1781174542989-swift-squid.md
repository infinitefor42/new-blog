# 移动端侧边栏修复方案：可展开的窄侧边栏

## 问题分析

1. **z-index 堆叠上下文问题**
   - `globals.css` 第 96-99 行：`body > * { position: relative; z-index: 2; }`
   - 导致抽屉无法正确覆盖页面内容

2. **侧边栏宽度问题**
   - 用户希望侧边栏初始宽度 80px，点击展开后显示"首页"和"博客"文字

3. **点击问题**
   - 堆叠上下文可能阻止了点击事件

## 修改方案

### 文件 1: `src/app/globals.css`

**修改点: 移除 body > * 的 z-index 设置 (第 95-99 行)**
```css
/* 删除这段代码 */
body > * {
  position: relative;
  z-index: 2;
}
```

### 文件 2: `src/components/layout/navbar.tsx`

**新增状态: 侧边栏展开状态**
```tsx
const [isDrawerExpanded, setIsDrawerExpanded] = useState(false);
```

**修改抽屉面板样式**
```tsx
// 抽屉容器
<motion.div
  initial={{ x: "100%" }}
  animate={{ x: 0 }}
  exit={{ x: "100%" }}
  transition={{ type: "spring", damping: 25, stiffness: 200 }}
  className={`fixed right-0 top-16 z-[60]
    bg-paper-bg/95 dark:bg-ink-deep/95
    shadow-2xl border-l border-t border-black/5 dark:border-rice-white/10
    md:hidden rounded-b-xl transition-all duration-300
    ${isDrawerExpanded ? "w-40" : "w-16"}`}
>
  {/* 关闭按钮 */}
  <div className="flex justify-end p-2">
    <button
      onClick={() => setIsMenuOpen(false)}
      className="w-8 h-8 flex items-center justify-center rounded-lg
        text-ink-gray dark:text-rice-white-dim
        hover:bg-ink-black/5 dark:hover:bg-rice-white/10
        transition-all duration-200"
    >
      <FiX className="w-4 h-4" />
    </button>
  </div>

  {/* 展开按钮 + 导航链接 */}
  <nav className="p-2 space-y-1">
    {/* 点击展开/折叠 */}
    <button
      onClick={() => setIsDrawerExpanded(!isDrawerExpanded)}
      className="flex items-center justify-center w-full py-3 rounded-xl
        text-ink-gray dark:text-rice-white-dim
        hover:bg-ink-black/5 dark:hover:bg-rice-white/10
        transition-all duration-200"
    >
      {isDrawerExpanded ? "收起" : "☰"}
    </button>

    {/* 展开后显示的导航链接 */}
    {isDrawerExpanded && (
      <>
        <Link
          href="/"
          className={`flex items-center justify-center w-full py-3 rounded-xl text-sm font-medium
            transition-all duration-200 no-underline
            ${isActive("/")
              ? "text-ink-black dark:text-rice-white bg-ink-black/5 dark:bg-rice-white/10"
              : "text-ink-gray dark:text-rice-white-dim hover:bg-ink-black/5 dark:hover:bg-rice-white/10"
            }`}
          onClick={(e) => handleNavClick(e, "/")}
        >
          首页
        </Link>
        <Link
          href="/blog"
          className={`flex items-center justify-center w-full py-3 rounded-xl text-sm font-medium
            transition-all duration-200 no-underline
            ${isActive("/blog")
              ? "text-ink-black dark:text-rice-white bg-ink-black/5 dark:bg-rice-white/10"
              : "text-ink-gray dark:text-rice-white-dim hover:bg-ink-black/5 dark:hover:bg-rice-white/10"
            }`}
          onClick={(e) => handleNavClick(e, "/blog")}
        >
          博客
        </Link>
      </>
    )}
  </nav>
</motion.div>
```

**添加关闭抽屉时重置展开状态**
```tsx
const handleNavClick = (e: React.MouseEvent<HTMLAnchorElement>, href: string) => {
  e.preventDefault();
  setIsMenuOpen(false);
  setIsDrawerExpanded(false);  // 新增
  router.push(href);
};

const handleMobileMenuToggle = () => {
  setIsMenuOpen((prev) => !prev);
  setIsDrawerExpanded(false);  // 新增：打开时重置为折叠状态
};
```

## 设计说明

- **折叠状态 (w-16 = 64px)**：只显示关闭按钮和展开图标
- **展开状态 (w-40 = 160px)**：显示"首页"和"博客"导航链接
- **过渡动画**：`transition-all duration-300` 实现宽度平滑过渡
- **修复 z-index**：移除 `body > *` 的 z-index 设置

## 验证步骤

1. `pnpm dev` 启动开发服务器
2. 切换到手机视图
3. 点击汉堡菜单：
   - 窄侧边栏（64px）从右侧滑入
   - 显示关闭按钮和展开图标（☰）
4. 点击展开图标：
   - 侧边栏宽度变为 160px
   - 显示"首页"和"博客"导航链接
5. 点击"首页"或"博客"：
   - 正常跳转，侧边栏关闭
6. 点击关闭按钮或遮罩：侧边栏关闭
