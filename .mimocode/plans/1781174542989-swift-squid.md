# 修复方案：头像位置 + 侧边栏直接展开

## 问题分析

1. **头像位置问题**
   - hero.tsx 中的 section 有 `min-h-screen` 和 `flex items-center justify-center`
   - 移除 `body > * { z-index: 2 }` 后可能影响了布局
   - 需要检查是否需要恢复部分样式

2. **侧边栏交互问题**
   - 当前点击汉堡菜单后 `isDrawerExpanded` 被设为 `false`，先显示折叠状态
   - 用户希望直接显示展开状态（显示"收起"、"首页"、"博客"）

## 修改方案

### 文件 1: `src/components/layout/navbar.tsx`

**修改点: handleMobileMenuToggle 函数 (第 36-39 行)**
```tsx
// 之前
const handleMobileMenuToggle = () => {
  setIsMenuOpen((prev) => !prev);
  setIsDrawerExpanded(false);  // 这行导致先显示折叠状态
};

// 之后
const handleMobileMenuToggle = () => {
  setIsMenuOpen((prev) => !prev);
  setIsDrawerExpanded(true);  // 直接展开
};
```

### 文件 2: `src/app/globals.css`

**恢复 body > * 的部分样式 (第 95-99 行)**
```css
/* 之前 - 完全注释掉了 */
/* body > * {
  position: relative;
  z-index: 2;
} */

/* 之后 - 恢复，但不设置 z-index */
body > * {
  position: relative;
}
```

## 验证步骤

1. `pnpm dev` 启动开发服务器
2. 切换到手机视图
3. 检查首页头像位置是否正常（应该垂直居中）
4. 点击汉堡菜单，验证：
   - 侧边栏直接显示展开状态（显示"收起"、"首页"、"博客"）
   - 不再先显示折叠状态
5. 点击"首页"或"博客"可正常跳转
